# UV Guide for ImageSlime 🚀

This guide explains how to use [uv](https://github.com/astral-sh/uv) to manage dependencies and run ImageSlime.

## 🎯 Why Use UV?

**uv** is a blazingly fast Python package and dependency manager that:
- ✅ Installs packages **10-100x faster** than pip
- ✅ Uses **less memory** and **disk space**
- ✅ Has **reproducible** dependency resolution
- ✅ Supports **Python 3.10+** natively
- ✅ Works seamlessly with **pyproject.toml**

## 📋 Quick Start

### 1. Install UV

```bash
# Install uv (macOS/Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
irm https://astral.sh/uv/install.ps1 | iex
```

### 2. Sync Dependencies

```bash
# Navigate to project directory
cd imageslime

# Sync all dependencies from pyproject.toml
uv sync
```

This will:
- Create a `.venv` directory with all dependencies
- Install the project in development mode
- Resolve all dependencies efficiently

### 3. Run ImageSlime

```bash
# Run the server
uv run python main.py

# Or run uvicorn directly
uv run uvicorn imageslime.main:app --reload
```

### 4. Access the App

Open your browser to: `http://localhost:8000`

## 🛠️ UV Commands

### Dependency Management

| Command | Description |
|---------|-------------|
| `uv sync` | Install all dependencies from pyproject.toml |
| `uv sync --dev` | Install all dependencies including dev dependencies |
| `uv add <package>` | Add a new package to pyproject.toml |
| `uv remove <package>` | Remove a package from pyproject.toml |
| `uv lock` | Update the lockfile |
| `uv export` | Export dependencies to requirements.txt |

### Running Commands

| Command | Description |
|---------|-------------|
| `uv run python main.py` | Run the main application |
| `uv run uvicorn imageslime.main:app` | Run with uvicorn |
| `uv run pytest` | Run tests |
| `uv run python test_basic.py` | Run basic tests |
| `uv run python setup.py` | Run setup script |

### Virtual Environment Management

| Command | Description |
|---------|-------------|
| `uv venv` | Create a virtual environment |
| `uv venv --python 3.11` | Create venv with specific Python version |
| `uv pip list` | List installed packages |
| `uv pip install <package>` | Install a package in the venv |

## 🔧 Configuration Files

### pyproject.toml

The main configuration file that uv uses to determine dependencies:

```toml
[project]
name = "imageslime"
version = "0.1.0"
requires-python = ">=3.10"
dependencies = [
    "fastapi>=0.104.0",
    "uvicorn[standard]>=0.24.0",
    "ultralytics>=8.3.237",
    # ... other dependencies
]

[project.optional-dependencies]
dev = [
    "pytest>=7.4.0",
    "black>=23.0.0",
]
```

### uv.toml (Optional)

Additional UV-specific configuration:

```toml
[project]
requires-python = ">=3.10"

[dependency-groups]
dev = [
    "pytest>=7.4.0",
    "black>=23.0.0",
]
```

### .python-version

Specifies the Python version to use:

```
3.10
```

## 🚀 Common Workflows

### Adding a New Dependency

```bash
# Add a package to pyproject.toml and install it
uv add requests

# Add a development dependency
uv add --dev pytest

# Sync after manual changes to pyproject.toml
uv sync
```

### Updating Dependencies

```bash
# Update all dependencies
uv lock --upgrade
uv sync --upgrade

# Update a specific package
uv add --upgrade fastapi
```

### Running Tests

```bash
# Run basic tests
uv run python test_basic.py

# Run pytest
uv run pytest

# Run with coverage
uv run pytest --cov=imageslime
```

### Development Workflow

```bash
# Install all dependencies (including dev)
uv sync --all-extras

# Run the server with auto-reload
uv run uvicorn imageslime.main:app --reload

# Format code
uv run black imageslime/

# Lint code
uv run ruff check imageslime/
```

## 🔄 Migration from pip

If you're migrating from pip to uv:

### 1. Remove old virtual environment

```bash
# Remove old venv if it exists
rm -rf venv/

# Remove pip cache
rm -rf __pycache__/ *.egg-info/ dist/
```

### 2. Install uv and sync

```bash
# Install uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# Sync dependencies
uv sync
```

### 3. Update scripts

Replace `python` with `uv run python` in your scripts.

## 💡 Tips and Tricks

### Faster Installs

```bash
# Use --frozen to skip lockfile updates (faster)
uv sync --frozen

# Use --no-dev to skip dev dependencies
uv sync --no-dev
```

### Environment Variables

```bash
# Set environment variables for uv
UV_PYTHON=python3.11 uv sync
UV_INDEX_URL=https://pypi.org/simple uv sync
```

### Clean Up

```bash
# Remove the virtual environment
rm -rf .venv/

# Remove the lockfile
rm -f uv.lock

# Remove Python cache
rm -rf __pycache__/
```

### Debugging

```bash
# Show dependency tree
uv pip tree

# Show installed packages
uv pip list

# Check for outdated packages
uv pip list --outdated
```

## 🐛 Troubleshooting

### "uv: command not found"

Make sure uv is installed and in your PATH:

```bash
# Check if uv is installed
which uv

# If not, install it
curl -LsSf https://astral.sh/uv/install.sh | sh

# Add to PATH (if not automatic)
export PATH="$HOME/.local/bin:$PATH"
```

### "Python version not found"

Make sure you have the required Python version installed:

```bash
# Check Python versions
ls /usr/bin/python*  # macOS
ls /usr/local/bin/python*  # Linux

# Install specific version with pyenv
pyenv install 3.10.13
pyenv global 3.10.13
```

### "Dependency resolution failed"

Try updating the lockfile:

```bash
# Remove old lockfile
rm -f uv.lock

# Regenerate lockfile
uv lock

# Sync again
uv sync
```

### "Module not found" errors

Make sure you're using `uv run` to execute commands:

```bash
# Wrong (uses system Python)
python main.py

# Right (uses uv's virtual environment)
uv run python main.py
```
